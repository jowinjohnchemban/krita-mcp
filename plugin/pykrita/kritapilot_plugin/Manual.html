Krita MCP Bridge

Lets AI agents (Claude, ChatGPT, Gemini, Cursor, Copilot, ...) see and edit your Krita documents through the Model Context Protocol (MCP).

  1. Enable this plugin, then restart Krita.
  2. Open Settings › Dockers › AI Bridge (MCP) (or Tools › Scripts › Krita MCP Bridge: show panel).
  3. Install the MCP server on this computer: pip install krita-mcp (or the wheel from the GitHub release).
  4. In the panel, pick your AI client under Connect an AI client and copy the snippet into it.

The panel shows what the AI is doing, can pause it or make it read-only, and can undo AI edits. The AI can only read and write files in the workspace folder shown in the panel.

Documentation: github.com/jowinjohnchemban/krita-mcp
